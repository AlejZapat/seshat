Construido con

JavaScript sin framework. Cada pieza resuelve una sola cosa.

  • Vite Empaquetado y servidor de desarrollo
  • Tailwind CSS Estilos por utilidades y tokens de tema claro y oscuro
  • Preline UI Componentes accesibles: menús, acordeones, modales
  • Material Symbols Iconografía de toda la interfaz
  • ApexCharts Gráficos
  • Leaflet Mapas
  • docx Exportación a documentos Word
  • Open-Meteo Fuente de datos meteorológicos históricos y de pronóstico

Cómo está armado

Seshat es una aplicación de una sola página. El shell se carga una vez y un cargador central inyecta cada vista bajo demanda, junto con el script que la inicializa.

La lógica compartida no vive aquí: autenticación, gráficos, mapas, exámenes, generación de documentos y acceso a datos vienen de un motor común que otras aplicaciones pueden reutilizar. Seshat aporta sus vistas, sus datos y su configuración de navegación.
